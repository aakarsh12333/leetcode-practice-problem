# LeetCode Practice Problems

A collection of Java solutions and practice problems for LeetCode and other
competitive programming exercises.

## Problems

- Maximum Subarray
- Count Digits
- Median of Two Sorted Arrays
- Longest Palindromic Substring
- Majority Element
- Koko Eating Bananas
- Find Pivot Index
- Power
- Reverse Integer

The Java files contain individual solution snippets intended for online judge
platforms. They may not all run as standalone programs.
